# PayPal AI Hackathon — Facts (verified Nov 6, Devpost)

- Site: https://paypalaihackathon.devpost.com/ · Rules: /rules · Blog: developer.paypal.com/community/blog/PayPal_AI_Hackathon/
- Format: global online. Submission Oct 1 – **Nov 12, 2026 21:00 Brussels**. Judging Dec 1–15. Winners ~Dec 21.
- Requirement: meaningfully uses **both PayPal + AI**. No tracks/problem statements.
- Team: no max; one Representative submits. Belgium eligible.
- Scale at audit (Nov 6): ~29,698 registrants. 8 main prizes + 12 sponsor prizes. Max 1 main/honorable + 1 sponsor per project.

## Must submit
- Working project: PayPal Sandbox + AI tool/model
- English text description (features/functionality)
- Functional demo: hosted URL OR complete setup/run instructions in repo (mockups don't count)
- List of tools used + how each was used
- Public repo (GitHub/GitLab/Bitbucket): source, assets, run instructions, OSS licence at top
- Demo video <3 min, public YouTube, shows it working (judges not required past 3:00)
